# MyGo PDF 路线图

[English](../en/plan.md)

## v1.0 前的验收

- **稳定宿主 API。** 承诺兼容性之前，用独立宿主验证导入路径、输入所有权、导航和回调契约。
- **完成原生交互验证。** 在 Windows 和 Linux 上检查键盘、鼠标、剪贴板、DPI 变化和退出流程。Linux 覆盖 Wayland 和 X11。在硬件支持时验证 macOS、Windows 和 Wayland 的捏合缩放，并验证 X11 的修饰键滚轮和键盘缩放。在支持的桌面平台记录屏幕阅读器对页面标签、权限允许的文本和链接激活的表现。
- **验证安装包。** 从空缓存构建，在支持的桌面平台检查签名、解包、内置 PDFium 资源和安装后启动。原生测试与交叉构建分别记录。
- **补齐回归覆盖。** 在已有的刷新、取消和密码测试之外，检查中文和从右到左文本、混合页尺寸、裁剪页和复杂扫描页。确认新显示的文档覆盖实际视口。
- **验证性能。** 参照[当前实测结果](performance.md)，在相同条件下复跑无窗口测试。普通文档的首屏和手势帧耗时 P95 均须控制在基线的 110% 以内，万页缩放基准的每次操作分配量须控制在其基线的 10% 以内。检查位图和瓦片预算。原生窗口时序、GPU 内存、进程 RSS 和生成中的位图分别测量。
